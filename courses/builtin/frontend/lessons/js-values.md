# 值、引用与类型转换

## 学完要能做到什么

能预测基础表达式的结果，区分值复制与共享对象，并用明确转换处理表单输入。

## 核心概念

JavaScript 的原始值包括字符串、数字、布尔、undefined、null、bigint 和 symbol。对象、数组和函数属于对象类型。变量保存的是值；复制对象值会让两个变量引用同一对象，并不会自动深复制其中内容。

const 限制重新赋值，不限制对象内部属性被修改。展开对象和数组只复制一层；嵌套对象仍然共享。更新复杂数据时，必须复制到真正发生变化的那一层。

表单输入的 value 通常是字符串。加号可能做字符串拼接，而严格相等不做跨类型转换。用 Number 等显式转换后还要处理空字符串、NaN 和业务范围；“转成数字”并不等于“通过业务校验”。

## 读懂一个最小例子

```javascript
const original = { score: 1 };
const alias = original;
alias.score = 2;
const copy = { ...original };
copy.score = 3;
console.log(original.score, copy.score);
```

输出 2 3。alias 与 original 指向同一对象；copy 是新的外层对象，这里的 score 是数字，因此之后互不影响。

## 两个容易混淆的地方

- const 禁止给变量重新赋值，数组内容仍可修改。
- 仅用 Number 不足以表达所有输入规则；空字符串会转成 0。

## 动手完成一个小作品

做一个分数调整器：输入当前分数和增量，显示结果，保留原始分数对象。

完成后，用下面的标准观察实际产出，而不是只看代码是否写完：

- 合法输入得到数值加法结果
- 空文本与非法数字有明确反馈
- 更新后原对象的值保持可解释且未被意外修改
