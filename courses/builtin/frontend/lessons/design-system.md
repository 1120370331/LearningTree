# 设计变量、状态与视觉层次

## 学完要能做到什么

能把颜色、间距和状态收敛为语义变量，建立清晰的正文、面板、选中与错误层次。

## 核心概念

设计变量应描述用途，例如 text-primary、surface、border、action，而不是把几十个相近的颜色散落在组件里。变量能集中调整，但仍要根据实际使用的前景和背景判断对比。

柔和不等于把所有文字变淡。大面积背景可用中性色，正文保持清晰，强调色集中用于操作和选中状态；错误、成功还应配合文字、图标或形状，避免只凭颜色判断。

组件应定义默认、悬停、焦点、禁用和错误状态。键盘焦点与鼠标悬停不是同一件事，不能为了截图干净而移除全部 outline。

## 读懂一个最小例子

```css
:root { --surface:#f9f9fb; --text:#1c2024; --action:#0d74ce; }
.card { background:var(--surface); color:var(--text); }
button:focus-visible { outline:2px solid var(--action); outline-offset:3px; }
```

语义变量表达用途，焦点态明确标示当前键盘位置。强调色只占少量面积，正文不因背景柔和而失去对比。

## 两个容易混淆的地方

- 低对比会增加辨认负担，柔和背景仍需要清晰文字。
- 焦点提示帮助用户知道下一次键盘操作会作用在哪个控件。

## 动手完成一个小作品

为学习卡片、按钮、输入框制作一组语义变量，并列出默认、选中、错误、禁用状态。

完成后，用下面的标准观察实际产出，而不是只看代码是否写完：

- 变量按用途命名且能复用
- 状态之间有清楚区别
- 正文与交互文字保持清晰且错误不只靠颜色

## 如何留下学习证据

先完成本节练习，再在底部开始测验。选择、填空、排序与代码阅读自动判分；简答、改错和实战需要你对照参考答案逐项自评。自评不会计入自动正确率，也不代表系统已经执行或审查你的代码。

把仍说不清的概念写进个人笔记。复习时先尝试回答“为什么统一变量后仍然需要分别考虑正文、按钮和禁用态？”，再核对参考解释。
