# 响应式与媒体适配

## 学完要能做到什么

能从内容拥挤的位置选择断点，处理图片和长文本，并保留缩放与触控操作能力。

## 核心概念

响应式让相同内容适应可用空间。先建立流式宽度、弹性轨道和合理的最小宽度，再在内容开始拥挤时使用媒体查询。设备品牌不是断点的依据。

viewport 的 width=device-width 帮助移动浏览器使用合适的布局视口。图片常用 max-width:100% 和 height:auto；长链接、不可换行文字及 flex 子项的最小尺寸也可能制造横向溢出。

适配不应依赖隐藏必要功能，也不应禁止用户缩放。除了宽度，还要考虑输入方式、焦点、文字放大和 reduced-motion 等用户偏好。

## 读懂一个最小例子

```css
.cards { display:grid; grid-template-columns:repeat(auto-fit,minmax(min(100%,240px),1fr)); gap:16px; }
img { max-width:100%; height:auto; }
```

min(100%,240px) 避免容器比 240px 更窄时仍被最小列宽撑开；图片保持比例。仍需观察长内容和组件内部约束。

## 两个容易混淆的地方

- 应修复布局并允许用户按需要放大文字。
- 固定宽高可能同时导致溢出和变形。

## 动手完成一个小作品

为一个内容卡片页制作窄、中、宽三种空间下的布局说明，并处理一条很长的 URL。

完成后，用下面的标准观察实际产出，而不是只看代码是否写完：

- 不同空间均可阅读和操作
- 长内容不迫使页面横向溢出
- 没有通过隐藏关键操作或禁止缩放应付适配

## 如何留下学习证据

先完成本节练习，再在底部开始测验。选择、填空、排序与代码阅读自动判分；简答、改错和实战需要你对照参考答案逐项自评。自评不会计入自动正确率，也不代表系统已经执行或审查你的代码。

把仍说不清的概念写进个人笔记。复习时先尝试回答“为什么 overflow-x:hidden 不能作为所有横向溢出的修复方案？”，再核对参考解释。
