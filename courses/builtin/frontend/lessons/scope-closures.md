# 作用域、函数与闭包

## 学完要能做到什么

能追踪函数访问的词法环境，解释闭包保存状态的原因，并识别循环回调共享绑定的问题。

## 核心概念

词法作用域由代码定义位置决定。函数查找变量时从当前作用域逐层向外，而不是到调用它的函数里寻找同名变量。参数也是函数的局部绑定。

let 和 const 具有块作用域。进入作用域到声明完成前处于暂时性死区，不能把它们简单理解成“提前变为 undefined”。var 是函数作用域，循环中的同一个绑定容易被多个回调共享。

闭包是函数与其引用的词法环境的组合。外层函数返回后，内部函数仍可能访问那个环境；多次调用工厂函数可以形成不同状态。闭包引用的是绑定，而不是自动拍摄所有变量的永久快照。

## 读懂一个最小例子

```javascript
function counter() {
  let value = 0;
  return () => ++value;
}
const a = counter();
const b = counter();
console.log(a(), a(), b());
```

输出 1 2 1。a 的两次调用共享一个 value；b 来自另一次工厂调用，拥有自己的环境。

## 两个容易混淆的地方

- 只要闭包仍可达，它所需的词法环境就可能继续存在。
- 修复变量捕获，而不是把延时改大或改小。

- 说明状态的词法位置和存活原因

## 如何留下学习证据

先完成本节练习，再在底部开始测验。选择、填空、排序与代码阅读自动判分；简答、改错和实战需要你对照参考答案逐项自评。自评不会计入自动正确率，也不代表系统已经执行或审查你的代码。

把仍说不清的概念写进个人笔记。复习时先尝试回答“多个定时回调捕获 var 循环索引时为什么容易得到相同值？”，再核对参考解释。
