# Flexbox 与 Grid 布局

## 学完要能做到什么

能依据一维或二维需求选择布局方式，并用轴、轨道和间隙解释布局结果。

## 核心概念

Flexbox 围绕主轴组织项目，justify-content 控制主轴，align-items 控制交叉轴。主轴由 flex-direction 决定，因此 column 下不能把 justify-content 简单记为水平对齐。

Grid 显式控制行列轨道，适合二维对齐。fr 分配扣除固定轨道和间隙后的剩余空间；minmax 可以限制轨道范围。Flex 与 Grid 可在不同层级组合。

order 和视觉网格位置可能改变外观顺序，但不会自动改变 DOM 阅读顺序。布局要同时考虑键盘、读屏和窄屏内容，而不是只把截图摆齐。

## 读懂一个最小例子

```css
.toolbar { display: flex; align-items: center; gap: 12px; }
.cards { display: grid; grid-template-columns: repeat(2, 1fr); gap: 20px; }
```

工具栏是一维排列，卡片区需要行列对齐。若卡片容器宽 620px，扣除一条 20px 间隙后，每列是 300px。

## 两个容易混淆的地方

- justify-content 始终沿主轴，不固定代表水平方向。
- 记住轴而非固定的水平/竖直口诀。

## 动手完成一个小作品

制作一个三列卡片列表，每张卡片的图标与按钮使用一维排列，窄屏变为单列。

完成后，用下面的标准观察实际产出，而不是只看代码是否写完：

- 外层与内层布局职责清楚
- 窄屏不出现必要内容被挤出
- 按钮顺序与键盘阅读一致
