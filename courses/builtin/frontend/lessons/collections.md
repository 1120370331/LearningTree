# 集合、数据变换与不可变更新

## 学完要能做到什么

能用 map、filter、reduce 与集合工具表达数据处理，并在保留原数据的前提下更新嵌套条目。

## 核心概念

map 把每项转换为一个新项，filter 选择满足条件的项，reduce 把多项累积为一个结果。回调应该清楚地返回所需值；使用这些方法不会自动阻止你在回调里修改原对象。

数组展开、slice 和 map 都可能保留内部对象引用。不可变更新要求为发生变化的层创建新值，并保留未变化对象的引用，以便行为可追踪且避免不必要复制。

Set 适合去重和成员判断，Map 支持非字符串键。sort 默认按字符串比较并修改原数组；数值排序应提供比较函数，并根据需要先复制或使用 toSorted。

## 读懂一个最小例子

```javascript
const items = [{ id: 1, done: false }, { id: 2, done: false }];
const next = items.map(item =>
  item.id === 2 ? { ...item, done: true } : item
);
const doneCount = next.filter(item => item.done).length;
```

只为 id 为 2 的条目创建新对象。原数组及原条目不被改写；完成数来自新数据，避免额外维护一个容易不同步的计数状态。

## 两个容易混淆的地方

- 默认比较使用字符串顺序；数值排序需要比较函数。
- 修复同时涉及比较规则和原地修改，不能只改其中一个。

## 动手完成一个小作品

制作任务列表的数据模块，支持按 ID 切换完成状态、筛选未完成项与计算完成数。

完成后，用下面的标准观察实际产出，而不是只看代码是否写完：

- 按 ID 更新准确且不依赖数组位置
- 原数据未被修改
- 派生数量与筛选结果一致
