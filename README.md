# LearningTree

面向个人学习者的网页应用：用学习树组织知识，通过自测、反思和间隔复习，持续获得学习反馈。

## 运行

使用 Node.js 24 LTS，在项目根目录执行：

```powershell
npm ci
npm run dev
```

打开 http://127.0.0.1:5173 。首次进入为**明确标记的示例空间**，点击「开始我的学习」可清空示例并创建自己的学习树。

```powershell
npm test           # 数据一致性、反馈规则、FSRS 调度测试
npm run typecheck  # TypeScript 检查
npm run build      # 构建到 dist/
npm run preview    # 预览构建产物
```

构建后的 `dist/` 可部署到普通静态托管服务。运行时无需后端、账号或 API 密钥，不依赖外部字体或 CDN。开发端口固定为 5173，避免端口漂移导致浏览器数据看似丢失。

## 使用流程

1. 创建学习树，为一个长期目标添加层级知识点；支持编辑、移动上级、笔记和资料链接。
2. 记录一次学习：时长、主观信心、收获与困惑，以及可选的正确题数/总题数。
3. 查看即时反馈、薄弱点和自测趋势。无自测数据时不推断成绩；正确率按最近最多 5 次自测的实际题数加权。
4. 为知识点写一道回忆题和参考答案。复习时先回忆，再看答案，最后诚实自评。
5. FSRS 根据自评和历史卡片状态安排下次复习。自评不混入自测正确率。
6. 在「偏好与数据」调整每日目标、导出备份或恢复备份。

## 数据与边界

- 当前为**本地个人版**，使用当前浏览器、当前站点 origin 下的 localStorage；不提供云同步、多用户或 AI 自动判卷。
- 请固定访问地址。`localhost`、`127.0.0.1`、不同端口是不同存储空间；换设备、换地址或清理浏览器前请导出备份。
- 写入前校验完整数据；写入失败不会更新页面内的数据。启动时遇到损坏数据会保留原文并提供恢复入口。
- JSON 导入先校验、展示数量，再由用户确认整体替换；不进行隐式合并。
- 单份数据最多 2 MB、100 棵学习树、1,000 个知识点、30 层树结构、20,000 条学习记录和 20,000 条复习记录。浏览器自身配额也可能限制可用空间。
- 删除学习树/知识点会在确认后删除相关子节点和记录。修改回忆题或答案会重置该卡的复习计划，历史日志保留。
- 反馈是基于记录的规则建议，不能替代专业评估；自测题目不同，趋势仅用于自我反思。

## 结构

| 文件                 | 职责                                   |
| -------------------- | -------------------------------------- |
| `src/domain.ts`      | 数据契约、关系校验、反馈统计、复习调度 |
| `src/storage.ts`     | 浏览器存储、导入校验、导出             |
| `src/demo.ts`        | 隔离标记的示例空间                     |
| `src/App.tsx`        | 导航、操作、持久化和错误处理           |
| `src/pages.tsx`      | 概览、学习树、复习、反馈、日志、设置   |
| `src/forms.tsx`      | 学习树、知识点、学习记录表单           |
| `src/components.tsx` | 可访问弹窗、知识树布局和共享组件       |
| `src/domain.test.ts` | 核心数据与调度回归测试                 |
| `references/`        | 搜索结果、参考清单、独立 Git 浅克隆    |

## 参考项目

参考项目克隆在当前目录的 `references/`，独立仓库不纳入本项目 Git。详见 [参考项目与取舍](docs/references.md)、[检索结果](references/search-results.json) 和 [来源/许可证/提交清单](references/manifest.json)。

```powershell
python scripts/collect-references.py          # 检索并收集
python scripts/collect-references.py --retry  # 复用元信息，补齐未完成克隆
```

脚本仅下载，不安装或运行参考仓库。它对自身 Git 子进程隔离本机 URL 重写配置，不修改用户全局配置。界面和业务实现为本项目编写，参考仓库代码未直接复制进产品。实际使用的运行时依赖包括 React、Lucide、Zod、ts-fsrs，其许可证保留在安装包中。

产品范围见 [交付约定](docs/intent.md)，验证结果见 [验收记录](docs/verification.md)。
