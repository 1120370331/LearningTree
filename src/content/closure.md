## 函数为什么能记住外部变量

闭包是函数与它的词法环境的组合。函数可以访问定义时所在作用域里的变量，即使外部函数已经返回。

```js
function createCounter() {
  let count = 0;
  return function next() {
    count += 1;
    return count;
  };
}
const a = createCounter();
const b = createCounter();
a(); // 1
a(); // 2
b(); // 1
```

## 每次调用，创建独立环境

a 和 b 来自两次 createCounter 调用，各自持有不同的 count。闭包捕获的是变量所在的环境，而不是把变量当前值复制成一张永远不变的照片。

## 作用域看定义位置

函数能访问哪些变量，由它定义的位置决定，不能因为换了调用位置就随意访问调用者的局部变量。

## 实际用途与代价

闭包可用于封装私有状态、回调和函数工厂。被仍然可达的闭包引用的数据可能继续留在内存中，因此不必要的大对象引用应及时释放。
