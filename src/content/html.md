## 用标签表达内容的含义

HTML 负责描述内容结构。标题、段落、导航和按钮应当使用能够表达这些含义的标签，让浏览器、读屏软件和维护代码的人理解页面。

## 结构与层次

`main` 表示页面主要内容，`nav` 表示导航区域，`article` 适合独立内容。标题层级要反映结构：先有主题，再有子主题，而不是为了字号大小随意选择 h1 或 h3。

```html
<main>
  <h1>我的学习记录</h1>
  <article>
    <h2>本周的发现</h2>
    <p>用自己的语言重新解释一个概念。</p>
  </article>
</main>
```

## 按钮和链接

改变当前界面状态的操作通常使用 button；前往另一个地址通常使用 a。原生按钮支持键盘焦点和触发行为，不应为了外观把所有操作都写成 div。

## 表单需要名称

输入框需要关联 label。placeholder 只是提示，输入后会消失，不能替代标签。图标按钮没有可见文字时，需要提供可访问名称。

## 图片的替代文本

传递信息的图片需要描述其意义。纯装饰图片可以使用空的 alt，避免读屏软件重复朗读无关内容。

试着用键盘 Tab 访问你写出的页面，确认每一个操作都能被找到并理解。
