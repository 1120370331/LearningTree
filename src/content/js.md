## 变量是绑定，不是容器的全部行为

JavaScript 的变量名可以绑定到一个值。let 允许重新赋值，const 不允许重新绑定，但这不代表 const 引用的对象被冻结了。

```js
const learner = { name: 'Lin', lessons: 0 };
learner.lessons += 1; // 合法：修改对象属性
// learner = {};     // 不合法：重新绑定 const

let count = 0;
count += 1;          // 合法
```

## 块级作用域

let 和 const 在块中定义的变量，不能随意从块外访问。函数内部的变量也有自己的作用域。阅读代码时，可以先确定每个变量在哪里声明，再追踪它被哪些函数访问。

## 比较与类型

`===` 不会为了比较而做隐式类型转换。`1 === '1'` 是 false。面对外部输入时，应当先转换并验证数据，再做逻辑判断。

## 对象与数组

对象通过引用传递。如果两个变量指向同一个对象，从其中一个入口修改属性，另一个入口也会观察到变化。浅拷贝只复制第一层；嵌套对象仍可能共享引用。

## 把逻辑放进函数

函数接收输入并返回结果。把重要计算写成明确的输入输出，通常比依赖很多外部可变变量更容易理解和验证。
