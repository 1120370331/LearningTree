先读 `docs/question-format.md`、目标节点讲义和 `src/quiz.ts` 的实际判分约定。题库源文件位于 catalog 指定的 `questions/<slug>.json`，由攻略作者维护，学习者界面不提供出题入口。

## 选题与答案

- 每道题对应一个明确目标。采用题型是为了测量理解、迁移或实际产出，不为凑齐数量强行套题型。
- 选择题干扰项来自常见误解，不能依靠选项长短、语气或“总是/从不”轻易排除。单选必须有唯一正确项；多选必须明确“选择全部正确项”。
- 判断题补充错误说法的反例。填空维护可接受别名，明确大小写与空白是否有意义，不使用任意正则或模糊语义匹配。
- 排序题只使用唯一、可解释的依赖顺序；若真实流程可并行，注明简化假设，或改用其他题型。
- 代码阅读提供完整的相关上下文、环境假设和预期结果。代码片段只展示，不会自动执行。
- 简答、代码改错、实战任务必须有参考答案及 2–8 条可观察评分标准，明确学习者需要交付的文字、代码或作品链接。不要把“写得好”“理解深入”作为标准。
- 自评题只有“对照标准是否达成”，不宣称机器审查过代码或作品。它们不进入自动正确率，也不用于伪造客观解锁成绩。

## 文件约定

稳定题目 ID 包含节点 ID 与语义后缀，例如 `fe-box-model-fill`。修正错字保留 ID；实质更换题目或答案时使用新题目 ID。附上题目解释，不将解析藏在选项中。

写完源 JSON 后通过 `npm run courses:build` 组装课程包。遵循用户的验收安排；未运行检查或浏览器时如实说明，不把生成成功表述为功能验证通过。
