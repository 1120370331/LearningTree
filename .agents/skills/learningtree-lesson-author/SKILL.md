读取目标节点在 `courses/builtin/frontend/catalog.json` 中的阶段、前置关系和对应题库。讲义源码放在 catalog 指定的 `lessons/` 文件，学习者在网页中只阅读和做个人笔记。

## 内容标准

- 开篇说明学完后可以完成什么具体操作，区分前置知识与本节新概念。
- 用一个贯穿的场景解释概念，提供可阅读的最小代码或 DOM/CSS 示例，并解释输出、关键行和边界条件。避免只有术语列表、外链或待补充提纲。
- 给出至少一个容易混淆的反例。对浏览器、React 或 TypeScript 行为说明必要前提，例如是否处于严格模式、是否为已兑现 Promise、是否依赖容器宽度。
- 将课堂练习写成可交付的结果，并给出可观察标准。不要把“阅读文档”“理解原理”本身当成作品要求。
- 对应测验的每个考点应在正文中讲到。题目需要新例子考迁移，避免直接重复正文句子即可猜中。
- 引用官方资料时使用明确页面地址，保留版本或适用范围。不能访问来源时不声称已核实最新版本。

## 网页约束

二级标题会生成本节导航。使用标准 Markdown 与标明语言的代码块；不嵌入脚本、未经处理的 HTML 应用或依赖外网才能理解的图片。代码题在当前产品中不会执行，讲义中的“预期输出”必须来自可解释的语言规则。

正文不包含用户当前得分、完成时间或个人笔记。更新讲义后运行 `npm run courses:build` 生成课程包即可；是否运行额外验证由当前用户要求决定。
