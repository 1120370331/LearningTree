# 学习树与学习工作台重做

本轮最终确认的布局：**蓝白配色，保留左侧全局导航，画布左上角项目导航，中央树图占满可用区域，右侧固定任务指挥台**。进入知识点后切换到学习内容页，通过底部栏开始测验。

## 实际采用的参考

- `hayyi2/react-shadcn-starter`：React + Vite + TypeScript 的轻量模板。本项目适配其语义化主题变量，改为蓝白色值；保留 MIT 声明于 `licenses/react-shadcn-starter.txt`。
- `satnaing/shadcn-admin`：参考简洁的工作台导航、面板密度和层次；它本身是演示型 Dashboard，不宣称把它原样当成 starter 安装。
- `andrico1234/beautiful-skill-tree`：阅读节点状态和父子解锁逻辑，借鉴锁定、可探索、通过验证的视觉区分。GPL 源码未复制进入应用。
- `Acamaeda/The-Modding-Tree`：阅读 `tree-node.css` 和画布连线代码，参考节点悬停、点亮和路线反馈。源码未复制进入应用。
- 图形交互实际采用 MIT 的 `@xyflow/react`，布局使用 `@dagrejs/dagre`；Markdown 内容使用 `react-markdown`。

四个新增参考均已克隆到 `references/`，来源和提交见 `references/design-manifest.json`。

## 页面与操作

- 学习者界面不提供「延伸节点」和节点删除入口。任务指挥台与阅读页提供「标记为已学」，可跳过当前节点并直接推进完成进度与推荐路线；标记在数据库确认保存后生效，刷新和课程更新后保留。

- 项目导航支持切换已有学习树、新建、编辑和删除项目，并提供概览、复习、反馈、日志、数据入口。
- 树图支持拖拽平移、滚轮/触控缩放、小地图导航、全图适配、定位当前节点、双击聚焦和当前前置路线高亮。选中节点不会重置用户的相机位置。
- 右侧任务指挥台持续展示选中节点的状态、探索/验证/巩固阶段、挑战要求、前置路线、笔记和历史。
- 主按钮为「开始学习」，直接进入学习工作台。已移除专注计时入口和相关组件。
- 学习工作台提供 Markdown 内容、代码示例、章节导航、资料链接和个人笔记。底部固定「开始测验」。进入测验前会保存当前笔记。
- 测验逐题作答，支持回看修改和信心自评；全部完成后统一判分、保存逐题答案/解析并更新技能树。
- 结果页展示本次成绩、近期加权成绩、逐题反馈、错题过滤和新解锁节点。新解锁节点可以继续进入学习。
- 学习者只阅读攻略、作答和记录笔记；讲义与测验由攻略提供者在 `src/lessons.ts`、`src/content/guide-catalog.ts` 及 Markdown 源文件中维护，前端没有题库或讲义编辑入口。
- 左上「推荐节点」会按内置路线与真实前置关系选择下一站，聚焦并放大到对应节点；「推荐路线」列出顺序、已验证状态和跨树来源。验证通过后自动推进推荐。
- 项目编辑可设置上级树与前置树；「添加子树」默认关联当前树。地图用 210×190 的节点和 3px 外圈边框区分子树（普通节点为 170×150）；点击进入、左上返回。前置依赖用带标签的虚线展示。树级完成要求其所有子树和前置树完成，空树不自动通过。

## 成长规则

1. **探索**：至少一条学习或复习记录；阅读笔记与学习成绩分开存储。
2. **验证**：最近最多 5 次自测按题数加权的正确率达到 80%，且这些自测累计至少 5 题。通过后解锁直接子节点。
3. **巩固**：验证通过，且最新自测之后有一次评分为「基本记得」或「轻松记得」的主动回忆。

前置关系用于引导学习，不是权限边界。任务指挥台会优先引导完成前置节点，也提供明确的提前学习入口；已经开始的节点不会因前置成绩回落而抹除个人进展。

## 数据兼容与内容边界

旧备份增加 `content`、`quiz` 的空默认值，保留原有笔记、学习记录和 FSRS 卡片。新增测验记录保存题目与答案快照，后续修改题库不会改变历史作答。

三个内置项目的全部 22 个节点均提供入门讲义与各 5 道测验，共 110 题。已有示例空间中尚无题库的内置节点可直接使用新增攻略；笔记、历史和已配置题库保留。未发布测验的自定义节点显示禁用的「测验准备中」，不会要求学习者出题。测验按标准答案在本地评分，不调用大模型。

旧备份的树关系默认独立、无前置。导入与保存拒绝失效引用、自依赖，以及嵌套和前置依赖组合产生的循环。删除上级树时保留子树与子树记录，并清理相关依赖。

## 验证范围

自动测试覆盖旧数据兼容、分数与逐题答案一致性、未完成测验拒绝提交、近期成绩与单次成绩区分、直接子节点解锁和阶段计算；既有 FSRS 与数据一致性测试继续执行。

浏览器验证应覆盖：项目切换 → 选择节点 → 开始学习 → 保存笔记 → 底部开始测验 → 作答 → 提交 → 查看解析和解锁 → 返回树图 → 刷新确认数据保留。
