# LearningTree：个人学习的持续反馈

用户已确认：面向个人学习者，用来持续获取学习反馈，网页端。本地目录原先为空。

## 第一版交付边界

- 可编辑的学习目标和层级知识树；内置明确标记的示例，支持从空白开始。
- 记录学习时长、反思、主观信心，以及可选的自测正确题数/总题数。
- 每个知识点可维护一道自己的回忆题和参考答案。采用 ts-fsrs 进行真实间隔复习；先回忆、再看答案、最后自评。
- 每次记录或复习后更新反馈：自测趋势、近期学习节奏、到期复习、薄弱项和具体下一步。没有证据时明确显示数据不足。
- 所有数据保存在当前浏览器；提供带校验的 JSON 导入/导出。无账号、云同步或伪装成 AI 的生成结果。
- 中文界面、键盘可用、窄屏适配。

## 验收路径

1. 新建学习树和知识点，填写回忆题。
2. 记录一次有自测结果的学习，查看即时反馈与趋势变化。
3. 进入到期复习，揭示答案并自评；确认下次时间和记录改变。
4. 刷新后数据仍存在；导出再导入能够恢复；损坏/断链数据拒绝写入。
5. 构建、核心数据契约测试和浏览器真实路径通过。

## 设计方向

采用“植物观察手册”主题：森林绿 #27604B、浅雾绿 #EDF2EA、纸白 #FAFBF8、深墨 #263B32、赭黄 #BD8A37、灰绿 #78867C。清晰的侧边导航、宽阔知识树画布和右侧下一步反馈形成工作台；唯一主视觉是会随学习记录变化的分支树。中文采用系统苹方/微软雅黑，标题与数字以 Georgia/系统衬线和紧凑等宽数字形成层次。拒绝装饰性大数字：指标必须指向实际学习证据。

参考代码保留在 references/ 独立浅克隆中，不执行参考仓库安装脚本，不把不同许可证代码直接拼入产品。借鉴交互和数据设计，依赖遵循自身许可证。
